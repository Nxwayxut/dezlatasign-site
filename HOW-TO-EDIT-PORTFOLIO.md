# Как самостоятельно обновлять страницу «Все работы»

Эта памятка написана для человека без опыта в коде. Перед любыми изменениями скачайте ZIP текущей версии сайта и сохраните его как резервную копию.

## Где находится новая страница

- Главная страница: `index.html`
- Страница всех работ: `works/index.html`
- Стили страницы: `css/works.css`
- Переключение галерей: `js/works.js`
- Изображения: папка `images`

## Как заменить заглушку настоящей работой

1. Подготовьте изображение в JPG, PNG или WebP.
2. Назовите файл латиницей без пробелов, например `logo-cosmetics-01.webp`.
3. Загрузите файл в папку `images` в GitHub.
4. Откройте `works/index.html`.
5. Нажмите значок карандаша **Edit this file**.
6. Найдите нужный раздел по его заголовку, например `Дизайн упаковки`.
7. Пока не удаляйте код самостоятельно: пришлите мне название файла и скажите, в какой раздел его добавить. Я дам точный готовый блок для вставки.

## Как добавить фотографию в существующую галерею

Внутри `works/index.html` найдите проект `Музей Выксы` или `Bomb Coffee`. Каждое изображение находится в таком блоке:

```html
<button class="gallery-card__slide" type="button" data-lightbox="../images/ИМЯ-ФАЙЛА.webp">
  <img src="../images/ИМЯ-ФАЙЛА.webp" alt="Описание изображения" width="1800" height="1272" loading="lazy">
</button>
```

Чтобы добавить новый слайд:

1. Скопируйте целиком один такой блок.
2. Вставьте его сразу после соседнего блока.
3. Дважды замените имя файла на имя новой картинки.
4. Измените текст после `alt=` на короткое описание.
5. В этой же галерее найдите число `3` в `data-gallery-total` не нужно: скрипт пересчитает фотографии сам.
6. Нажмите **Commit changes**.

## Как изменить название раздела

1. Откройте `works/index.html`.
2. Найдите нужный заголовок внутри `<h2>...</h2>`.
3. Измените только текст между тегами, не удаляя сами `<h2>` и `</h2>`.
4. Нажмите **Commit changes**.

## Когда изменения становятся видны

- Пока вы только редактируете файл и не нажали **Commit changes**, посетители ничего не видят.
- После нажатия **Commit changes** Cloudflare автоматически публикует новую версию.
- Обычно обновление занимает от нескольких секунд до нескольких минут.
- Если старая версия осталась в браузере, нажмите `Ctrl + F5`.

## Как безопасно отменить ошибку

1. В GitHub откройте вкладку **Commits**.
2. Найдите последний рабочий коммит.
3. Не пытайтесь удалять много кода вручную — пришлите мне скрин или ссылку на коммит, и я дам точные действия для возврата.
